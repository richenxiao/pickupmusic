本轮修复：Orbit 的折角 / 毛刺 / 断裂

这一轮修的两件事（只动了 Orbit，其余元素一行未改）：

① 交叉点处的折角 / 台阶
缺口原本用线性插值填补 —— 直线接在实测曲线上，接缝处斜率不连续， 放大后就是一道折角。改成 Whittaker 惩罚最小二乘 （min Σwᵢ(yᵢ−vᵢ)² + λΣ(Δ²yᵢ)²，被遮住的样本 w=0）—— 缺口由罚项给出曲率连续的插值，接缝没有折角。

② 纹路穿过处的凸起 / 毛刺
轨道带吞掉唱片纹路时，合并 run 的那条边其实是纹路的边而不是轨道的边， 于是边界被「带偏」十几个样本。邻域中位数（Hampel）只能抓孤立尖点，抓不到这种持续偏移。 改成 先测三条纹路，再把落在纹路上的那一边判为不可信（交插值）； 另外迭代重加权（IRLS）在这里会塌缩成一条直线，已弃用，改用「全权重拟合 → 一次性剔除残差大的样本 → 重解」。

③ 折线刻面
轨道带原本用 L 折线（0.25° 一段），高倍放大能看到刻面。 改成 三次贝塞尔输出（Catmull-Rom 切线，两端保留单侧切线以保住尖头）。

结果：Orbit 单独渲染径向不连续点 0 处、宽度突变 0 处； 整图径向边缘最大偏差 46.25 → 2.75 → 1.25 单位 （中位 0.00、90% 分位 0.50）；与原稿 IoU 0.96536 → 0.97675。

另外：唱片外圆的让位已归属为轨道穿过的合成效果，不是 Record 的几何 —— 关闭 Orbit 时 #ring-masked 的 mask 自动失效，唱片恢复完整一圈 （隔离验收 A：外圆缺失角度 0 个）。
